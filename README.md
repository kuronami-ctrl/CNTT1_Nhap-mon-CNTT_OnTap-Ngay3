# Trung tâm tiếng Anh (TTA)

## Giới thiệu

**Trung tâm tiếng Anh TTA** là dự án quản lý thông tin khóa học, học viên và học phí. Tài liệu giúp việc quản lý dữ liệu trở nên *đơn giản, rõ ràng và thuận tiện*.

## Cấu trúc thư mục

| Thư mục | Nội dung |
|---|---|
| `archive/` | Lưu trữ các tài nguyên cũ |
| `data/` | Chứa dữ liệu học viên và bảng học phí Excel |
| `docs/` | Chứa tài liệu, lịch học |
| `logs/` | Chứa nhật ký hoạt động hệ thống |
| `media/` | Chứa hình ảnh và logo trung tâm |

## Quy trình đăng ký học tại TTA

1. Học viên tìm hiểu các khóa học và mức học phí.
2. Học viên chọn khóa học phù hợp và đăng ký số tháng học.
3. Nhân viên kiểm tra thông tin, tính học phí và xác nhận đăng ký.

## Lệnh kiểm tra dự án

Sử dụng PowerShell để xem nội dung thư mục dự án:

```powershell
Get-ChildItem
Get-ChildItem .\data
Get-ChildItem .\docs
Get-ChildItem .\logs
Get-ChildItem .\media
```
